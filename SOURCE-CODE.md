# Source code availability

The build configuration and original TechRefreshing Linux scripts are
available at:

https://github.com/Techrefreshing/TR-Linux

The image is built from Debian 13 binary packages. The installed package
manifest is available at:

    /usr/share/doc/tr-linux/package-manifest.txt

Matching Debian source packages can be obtained with Debian's normal source
repositories, from https://sources.debian.org/, or from
https://snapshot.debian.org/. On a Debian-compatible system with source
repositories enabled, run:

    apt source PACKAGE

For GPL-covered components for which TechRefreshing is responsible for source
distribution, TechRefreshing offers the complete corresponding source in a
machine-readable form for no more than the reasonable physical cost of
providing it. This written offer is valid to any recipient of TechRefreshing
Linux 1.0 through 31 December 2029. Request source through:

https://github.com/Techrefreshing/TR-Linux/issues

Include the ISO filename, SHA-256 checksum, package name, architecture, and
version in the request. Third-party source remains under its original licence.
