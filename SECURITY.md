# Security policy

## Supported release

Security fixes are currently considered for TechRefreshing Linux 1.0 while it
is listed as supported in the repository release notes. Most package security
updates are delivered through Debian's security repositories.

## Reporting a vulnerability

Do not publish passwords, private keys, personal data, or an immediately
exploitable proof of concept in a public issue.

For a TR Linux-specific vulnerability, open a minimal GitHub issue requesting
private contact and include:

- affected TR Linux version and architecture;
- affected component and package version;
- impact and reproducible conditions; and
- whether public disclosure is already planned.

https://github.com/Techrefreshing/TR-Linux/issues

For an upstream Debian or application vulnerability, also follow that
project's security reporting process. Installing available updates remains
the user's responsibility.
