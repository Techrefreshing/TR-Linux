# Support

TechRefreshing Linux is a community project provided without guaranteed
response times or commercial support.

- Project and downloads: https://github.com/Techrefreshing/TR-Linux
- Issue reporting: https://github.com/Techrefreshing/TR-Linux/issues
- Creator website: https://techrefreshing.com/
- Linux guides: https://linuxano.com/

Before reporting a problem:

1. install all available Debian and Flatpak updates;
2. reproduce the problem in the live environment where practical;
3. record the exact hardware, TR Linux version, package version, and error;
4. remove personal information from screenshots and logs; and
5. search existing issues for the same problem.

General Debian, KDE, Calamares, Firefox, LibreOffice, and other upstream
questions may be best handled by those projects' documentation and support
communities.
